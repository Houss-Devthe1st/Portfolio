ELibrary

A full-stack online library with user accounts, book borrowing and admin tools, built with ASP.NET MVC and Microsoft SQL Server.

Type
Web application
Built with
  • ASP.NET MVC
  • C#
  • Bootstrap
  • SQL Server

Overview

ELibrary is an online collection of digital resources, such as e-books, journals and multimedia content. Users can access, search and borrow from it wherever they are, without the space and cost of a physical collection.

The sections below explain the main parts of the system shown in the demo.

Architecture

I built the site with ASP.NET and C#, with a dynamic front end and back end. I used the Model-View-Controller (MVC) pattern because it separates data, logic and interface, which keeps the code organized, maintainable and scalable. ASP.NET's cross-platform support keeps deployment flexible, and features like master pages and server controls make components reusable.

Interface

I styled the site with Bootstrap for a professional look. Its ready-made components (navigation bars, buttons, forms and cards) and grid system mean far less hand-written HTML and CSS.

Bootstrap also displays the signed-in user's name, so the site feels more personal.

Database

An e-library stores a lot of information: user accounts, books, and the e-books people download or borrow. I chose Microsoft SQL Server for its enterprise-grade reliability, deep integration with the Microsoft ecosystem, business intelligence and analytics tools, and strong security and availability.

Users and admins

The site implements full CRUD operations and tells admins apart from regular users. Admins can also:

  • Add books and users to the database
  • Update the status of a borrowed book
  • Update the status of a user
  • Add authors, so users can search for books by author
